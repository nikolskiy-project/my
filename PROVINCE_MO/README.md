# Province MO Search — справочник для Province RP #3

Версия подготовлена на базе оригинального `province-law-main.zip`: **сохранены исходные `reconfig-base.css`, `style.css`, `site-ui.js` и логотип**, переработано только содержимое карточек и поиск. На сайте нет добавления/импорта правил.

## Запуск

1. Распакуйте архив полностью.
2. Откройте `index.html` двойным кликом: поиск работает **без интернета, Python и сервера**.
3. При желании запустите `START_WINDOWS.bat` для локальной версии `http://127.0.0.1:8765/` (нужен Python 3).

## Что входит

- `2.txt`: общевоинские уставы — **120 исходных пунктов**. Пункты внутренней службы, дисциплинарного, комендантского/караульного и строевого уставов имеют раздельные идентификаторы, даже если номер совпадает.
- `3.txt`: положение о зонах воинской части и военкоматов — **19 пунктов**.
- `4.txt`: поставки боеприпасов МВД — **25 пунктов**.
- `1.txt`: поставки частным охранным предприятиям (ЧОП) — **11 пунктов**, самостоятельный фильтр.
- `5.txt`: информационный раздел МО — **144 поисковые записи**: команды, доклады, тен-коды, наряды и бинды. Номера для этого раздела — служебные идентификаторы поиска, не официальные номера правил.
- ОПГО — **18 кратких записей** из старой сборки. ВПС — **нет текста**. Эти две темы не были в пяти загруженных TXT; на сайте указана неполнота.

**Итого: 319 записей из полных текстов пользователя, 18 кратких записей, ВПС пока без данных.** Все тексты пользователя лежат неизменёнными в `sources/`. Из TXT недоступны карты/изображения, если они были на форуме.

## Как заполнить ВПС и ОПГО

1. Попробуйте `UPDATE_VPS_OPGO_WINDOWS.bat` — он скачивает тексты двух публичных тем с форума (требуются интернет и Python).
2. Если форум блокирует скачивание: `UPDATE_BROWSER_WINDOWS.bat`. Он установит Playwright/Chromium, откроет форум в браузере и позволит войти в учётную запись.
3. Или сохраните тексты в `imports/vps.txt` и `imports/opgo.txt`, затем запустите `py -3 scripts\update_rules.py`.

Полученные тексты вставляются в `data/rules.json` и `data/rules.js`. Ни один пользовательский документ МО при этом не заменяется.

## Проверка

- `node tests/search.test.cjs`
- `python -m unittest discover -s tests`

Поиск работает локально. Синонимы и исправление опечаток реализованы в `assets/search-core.js`; для ответов всегда отображается полный текст найденной записи. Изменения правил на форуме после даты создания файлов не обновляются автоматически.
